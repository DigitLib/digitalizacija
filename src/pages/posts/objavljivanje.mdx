## Рад у скупу алата за дигитализацију ResCarta Toolkit

Скуп аларта ResCarta Toolkit састављен је од више засебних програма којима се обавља процес дигитализације. У нашем процесу рада најчешће се користе:

* 01 - ResCarta Metadata Creation Tool (унос метаподатака према типу дигиталног објекта)
* 02 - ResCarta Data Conversion Tool (конверзија у базу и OCR текстуалне грађе)
* 03 - ResCarta Textual Metadata Editor (исправка текстуалног садржаја - OCR) - није обавезан
* 05 - ResCarta Collections Manager (уређивање колекција)
* 06 - ResCarta Indexer (индексација - база за претрагу)
* Веб апликација (садржана у инсталацији)

### Инсталација
За инсталацију програма ResCarta Toolkit непходно је имати инсталацију Java (неке установе које користе БИСИС или КОБИС имају већ инсталирану). Уколико нема инсталације можете преузети са овог линка <a href="https://adoptium.net/temurin/releases/?os=windows&package=jdk&version=11&arch=x64" target="blank">OpenJDK 11</a> (за Windows системе)

Инсталација програма ResCarta Toolkit доступна је на линку <a href='https://drive.google.com/file/d/17Fqp4rpN6qGlft2usQW0k2pQ6g7hhCHS/view?usp=sharing' target='_blank' >ResCarta Toolkit</a>

#### 01 - ResCarta Metadata Creation Tool

Ид број дигиталног објекта има три скупа по 8 карактера (нпр. bmbbib01/kolekc01/00000001):
- bmbbib01(ид установе се дефинише само једном)
- kolekc01 (назив колекције)
- 00000001 (број дигиталног објекта)

НАПОМЕНА: уносити само латинична слова, енглеска, без наших.

Object as file - прави објекат од само једног фајла (пдф или фотографије се дефинишу као фајл - објекат)

Object as directory - прави објекат од садржаја у фолдеру (публикација од 100 сртраница има 100 скенова али је то целина у фолдеру)

НАПОМЕНА: За конверзију тип дигиталног објекта одређује структуру у главног бази. Језик публикације дефинише језик за OCR (подржава више језика)

Текстуално упутство доступно је на линку <a href='https://drive.google.com/file/d/10EDRxzOQvUpPRT3XN3W3vx1cBARMbnTG/view?usp=sharing' target='_blank'>ResCarta Metadata Creation Tool</a>

#### 02 - ResCarta Data Conversion Tool

Конверзија скенираног материјала у базу, OCR.

Како је дефинисан тип објекта (као фајл или фолдер) тако и подесите конверзију. За OCR само штиклирајте ако постоји текст, или искључите ако нема текста (нпр. фотографија, мапа, ...)

Базу RCDATA01 складиштите по жељи (поље "Destination directory"). Сви следећи кораци се раде учитавањем базе.

Додатне језике за OCR можете преузети из <a href='https://github.com/tesseract-ocr/tessdata_best' target='_blank'>Tesseract базе</a>

#### 03 - ResCarta Data Conversion Tool
Овај корак <u>није обавезан</u> али ако желита да коригујете добијен текст учитајте конвертован објекат (нпр. bmbbib01/kolekc01/00000001)

#### 05 - ResCarta Collections Manager
Прављење колекција и потколекција, убацивање и склањање дигиталних објеката.

Текстуално упутство доступно је на линку <a href='https://drive.google.com/file/d/1lRvPBCmSaMXDQ5y1F8gnj55_OMFUX3v4/view?usp=drive_link' target='_blank'>ResCarta Collections Manager</a>

#### 06 - ResCarta Indexer
Прављење индкес базе за претрагу. Учитате базу RCDATA01 (са локације на коју сте сачували), аутоматски се прави (приликом првог покретања програма) индекс база index.ir7 у главној бази RCDATA01. Од опција само "Verbose" треба штиклирати.

НАПОМЕНА: Уколико се појави проблем са индекс базом може се урадити комплетна индексација штиклирањем опције "Rebuild index".

#### Веб апликација
У веб апликацији на локалном рачунару генеришу се сличице. Приликом првог покретања апилације повежите базу RCDATA01 у админ панелу.

Ову веб апликацију можете користити и на рачунару који ће бити јавно доступан.

ПРЕПОРУКА: За инсталацију и одржавање рачунара на коме је јавно доступна веб апликација ангажујте локалног сарадника који може брзо реаговати на лицу места. Ако у установи имате запосленог информатичара још боље.
